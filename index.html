MeshCore RX Monitor

Connects via Bluetooth to a MeshCore companion radio and monitors incoming LoRa mesh packets in real time — tracking which packets were received, via which repeaters, and with what signal quality.

Getting started

Click Connect Bluetooth and select your MeshCore companion device. Packet data appears automatically as the device picks up LoRa traffic. Previously paired devices appear as quick-connect buttons.

Key concepts
Repeater
direct means a flood-routed packet was received at the first hop — no intermediate repeater. Otherwise the ID shown is the last mesh node that forwarded the packet toward your device.
RSSI
Received Signal Strength Indicator — radio power in dBm. Less negative = stronger. −70 dBm: excellent  ·  −120 dBm: very weak.
SNR
Signal-to-Noise Ratio in dB. Positive = signal is above the noise floor. LoRa can decode even at negative SNR (down to about −20 dB).
Noise floor
Background RF noise level, estimated as RSSI − SNR. Shown as the shaded area on the RSSI chart.
Active
Number of unique packets in the current time window (within the auto-remove TTL — applies to the Messages table, charts, and 3D map).
Total RX
All packet arrivals this session — the same packet heard via two repeaters counts as two.
Message type
Packet type abbreviations: AD = Advert, GT = GroupText, TR = Traceroute, RS = Response, RQ = Request, PN = Ping.
Column order in Messages
Repeater columns are sorted by: packets in the last 5 min (desc), then last RSSI (best first), then last SNR, then total RX count, then alphabetically.
Interactions
  • Click an RSSI or SNR cell in Messages → see full packet detail and raw hex
  • Click a chart dot or legend label → highlight that repeater across both charts; click again or elsewhere to deselect
  • Click column headers in Seen Repeaters → sort the table (click again to reverse)
  • Click section titles → collapse / expand that section
  • Click the hex string in a packet detail → copies it to clipboard
  • The Sound checkbox plays a beep on each new packet; pitch reflects signal strength
  • In Signal 3D map, allow location, then drag to rotate / scroll to zoom. Each bead sits at your browser's GPS position with height proportional to RSSI. Click a bead to highlight that repeater (also synced to the RSSI / SNR charts). Choose between Mapy.com (basic, outdoor, winter, aerial / ortofoto) and OpenStreetMap (standard, OpenTopoMap) as the floor tiles.
