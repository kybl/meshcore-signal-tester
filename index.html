MeshCore RX Monitor

Connects via Bluetooth to a MeshCore companion radio and monitors incoming LoRa mesh packets in real time — tracking which packets were received, via which repeaters, and with what signal quality. Monitoring is entirely passive — the app only listens, it does not transmit any packets (no pings, no requests).

Getting started

Click Connect Bluetooth and select your MeshCore companion device. Packet data appears automatically as the device picks up LoRa traffic. Previously paired devices appear as quick-connect buttons. Click any section title to collapse or expand that section. Use ⏸ Pause / ▶ Resume to suspend data collection without disconnecting — collection pauses automatically on disconnect and resumes on reconnect.

Key concepts
Repeater
direct means a flood-routed packet was received at the first hop — no intermediate repeater. Otherwise the ID shown is the last mesh node that forwarded the packet toward your device.
RSSI
Received Signal Strength Indicator — radio power in dBm. Less negative = stronger. −70 dBm: excellent  ·  −120 dBm: very weak.
SNR
Signal-to-Noise Ratio in dB. Positive = signal is above the noise floor. LoRa can decode even at negative SNR (down to about −20 dB).
Noise floor
Background RF noise level, estimated as RSSI − SNR. Shown as the shaded area on the RSSI chart.
Repeater ID prefix resolution

Path IDs can arrive as 1–3 byte prefixes of the full 4-byte node ID. The app resolves them progressively:

  • When a longer ID arrives for a node already seen as a shorter prefix, the column is promoted to the longer label (e.g. 12 → 1234).
  • If a short prefix turns out to be ambiguous — it matches two or more known distinct nodes — those ambiguous packets are grouped under a combined label (e.g. 1234/1289) while each specific node keeps its own column.
  • Each additional sibling is added to the combined label (e.g. 1111/1122/1133). The combined column always represents packets whose exact origin is uncertain among those nodes.
  • If a more-precise ID later arrives for one of the siblings, its part of the label is updated too (e.g. 1234/1289 → 123456/1289).
