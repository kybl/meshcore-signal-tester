🔔 Sound Lab

A tuning playground for the packet-received sound. Drag the sliders and tap Play (it auto-plays on change too). When it sounds right, copy the values at the bottom into _playRxSound in app.js.

Test conditions

Test SNR (pitch of 2nd note)
0 dB = base pitch · ±10 dB = ±1 octave
Length preset
Ring-out length
how long the final note rings

Tone

Base frequency
pitch of the fixed reference note
Volume
Attack
shorter = more "ping" / click · longer = softer
Upper-partial decay
0 = highs ring as long as fundamental (more shimmer) · higher = highs die sooner (duller)

Brightness (lowpass filter)

Cutoff
lower = warmer/muffled · higher = brighter/more crystalline
Resonance (Q)

Partials (harmonics)

on×freqamplitude
×freq = harmonic multiplier (2 = octave, 3 = fifth above that…). Non-integer values (e.g. 4.01, 6.01) add glassy, slightly-detuned shimmer.

Two-note shape

Reference-note volume

Reference-note length
fraction of the ring-out length
2nd-note delay
0 = both notes together (chord) · larger = "di-iing"
